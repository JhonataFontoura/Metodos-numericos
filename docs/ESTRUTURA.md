# Estrutura do Métodos Numéricos Acadêmico Pro

Este arquivo explica onde cada assunto fica no projeto.

## Representação Numérica

```txt
representacao_numerica/
├── troca_de_base/
├── ponto_flutuante/
├── erros_numericos/
└── aritmetica_basica/
```

Use essa área para conteúdos de representação de números reais, bases, ponto flutuante, erros, frações, MMC e MDC.

## Equações Não Lineares

```txt
equacoes_nao_lineares/
├── bissecao/
├── falsa_posicao/
├── newton/
├── secantes/
└── ponto_fixo/
```

Cada método possui sua própria pasta, para facilitar manutenção e estudo.

## Sistemas Lineares

```txt
sistemas_lineares/
├── gauss/
├── lu/
├── cholesky/
└── metodos_iterativos/
```

Aqui ficam métodos diretos e iterativos para resolver sistemas lineares.

## Interpolação Polinomial

```txt
interpolacao_polinomial/
├── lagrange/
├── newton_diferencas_divididas/
└── minimos_quadrados/
```

Aqui ficam os métodos de interpolação e ajuste.

## Cálculo Numérico

```txt
calculo_numerico/
├── integracao/
└── derivacao/
```

Aqui ficam integração e derivação numérica.
